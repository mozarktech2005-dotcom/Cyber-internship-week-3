PDF Password Cracking – John the Ripper & Networkwalks

Project Overview

This project documents Week 3 practical training at Networkwalks, focusing on PDF password cracking using John the Ripper (JtR) and Networkwalks' custom password-cracking tool.

Tools Used

Tool| Purpose
Kali Linux| Testing environment
John the Ripper| Password cracking
pdf2john| PDF hash extraction
Networkwalks Custom Tool| Password cracking
Wordlists| Dictionary attacks

Practical Activities

1. Identified four password-protected PDF files.
2. Extracted their password hashes using "pdf2john".
3. Saved the extracted hashes in "hashes.txt".
4. Used John the Ripper to perform dictionary-based password attacks.
5. Used Networkwalks' custom tool to perform similar password-cracking exercises.
6. Examined the recovered passwords.

Skills Gained

- PDF password hash extraction.
- John the Ripper usage.
- Dictionary-based password attacks.
- Working with custom password-cracking tools.
- Understanding password security and recovery.

Conclusion

The practical provided hands-on experience in PDF password cracking using John the Ripper and Networkwalks' custom tool. It improved my understanding of hash extraction, dictionary attacks and password security.
